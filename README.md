# Chatbot
This is RCC Chatbot which can answer queries based on IS 456:2000, the code book on the practices of Reinforced Cement Concrete Structures.


# How to run?
### STEPS

Clone the repository

```bash
Project repo: https://github.com/ChappaAlekhya/Chatbot.git
```

### STEP 01 - Create a new virtual environment after opening the repository

```bash
conda create -n rcc python=3.10 -y
```


```bash
conda activate rcc
```


### STEP 02 - install the requirements
```bash
pip install -r requirements.txt
```
